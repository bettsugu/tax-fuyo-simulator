# tax-fuyo-simulator

2か所の給与を入力して、税金と扶養の基準との関係を見ながら、あとどれだけ働くかを検討するためのアプリ。

## 決まっていること

- スマホで使うWebアプリにする（GitHub Pagesに置き、ホーム画面に追加して使う）。使うのはiPhone。
- 住んでいる市町村や共済組合の名前など、身元の手がかりになるものはプログラムに書かない。
- 入力した金額は端末の中だけに保存する。外部には送らない。
- プログラムには基準額と計算の仕組みだけを書く。実際の金額はこのリポジトリに入れない。
- 入力内容を書き出して戻せる機能を付ける（端末のデータが消えたときのため）。
- 画面は月ごとに2か所の金額を入れるだけにし、「各基準まであといくら」を一目で見せる。

## 作る順番

1. 各基準まであといくら ＋ 本人の所得税・住民税
2. 配偶者側の税額への影響（配偶者控除・配偶者特別控除）
3. 扶養から外れた場合の負担（健康保険料・年金保険料、扶養手当）

1が使えることを確かめてから、2と3を足す。

## 数字を入れる前に確認するもの

基準額は一次情報で確認してから入れる。出どころと確認日をプログラムの近くに残す。

- [x] 所得税（令和8年度の税制改正後の基準）：国税庁の資料で確認済み
- [x] 住民税：総務省の資料と、住んでいる市の公式サイトで確認済み。級地と均等割の金額は市町村で違うので、プログラムには書かず、画面の「設定」で端末に入れる
- [x] 被扶養者の認定基準：共済組合の「被扶養者認定に係る基準及び取扱い」令和8年度版で確認済み
  - 配偶者は年130万円未満。月額の目安は108,334円未満
  - 1月〜12月の合計で判定するのではない。労働条件通知書を出せる場合は「労働契約で定められた賃金から見込まれる年間収入」で見る（通知書に決まりのない残業代などは含めない）
  - 通知書を出せない場合や給与以外の収入がある場合は、通勤手当を含む総支給額の「過去1年間の累計」で見て、130万円を超えた月の翌月1日から外れる
  - 人手不足などによる一時的な増加は、事業主の証明があれば連続2回まで認められる
  - 2か所とも労働条件通知書はないので、アプリは「過去1年間の累計」の見方で出す。去年の給与と月々の交通費を入れると、月ごとに直近12か月の累計と残りが出る
- [ ] 勤務先で本人が社会保険に加入する条件（まだアプリに入れていない）
- [ ] 扶養手当の基準
- [x] 青色事業専従者に当たるかどうか：当たらない（専従者給与はなし）
